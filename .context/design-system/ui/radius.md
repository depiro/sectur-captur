# Captur — Border Radius

## Radius System

Rounded corners follow a restrained and functional system.

---

# Radius Tokens

| Token | Value | Usage |
|---|---|---|
| `--radius-sm` | 4px | Badges, inputs |
| `--radius-md` | 8px | Cards, buttons |
| `--radius-lg` | 12px | Modals, panels |
| `--radius-full` | 9999px | Avatars, toggles |

---

# Usage Rules

## Small Radius
Used for:
- Inputs
- Checkboxes
- Small UI elements

## Medium Radius
Default radius for most components.

## Large Radius
Reserved for floating surfaces and overlays.

## Full Radius
Only for perfectly rounded elements.
