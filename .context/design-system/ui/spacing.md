# Captur — Spacing

## Philosophy

Spacing follows a strict 4px system inspired by Stripe.

Every:
- margin
- padding
- gap
- spacing relationship

must use predefined spacing tokens.

---

# Spacing Scale

| Token | Value | Usage |
|---|---|---|
| `--space-1` | 4px | Metadata gaps |
| `--space-2` | 8px | Badge padding |
| `--space-3` | 12px | Input padding |
| `--space-4` | 16px | Card padding |
| `--space-5` | 20px | Form field spacing |
| `--space-6` | 24px | Compact sections |
| `--space-8` | 32px | Component separation |
| `--space-10` | 40px | Mobile sections |
| `--space-12` | 48px | Desktop sections |
| `--space-16` | 64px | Hero padding |
| `--space-24` | 96px | Large content separation |

---

# Layout Rules

- Never use arbitrary spacing values
- Prefer vertical rhythm consistency
- Use spacing tokens exclusively
